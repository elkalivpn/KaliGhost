# KaliGhost 🐉👻

> **No es solo Kali. Es un agente de IA que no deja rastro.**

La distribución Linux ofensiva definitiva que fusiona la portabilidad de **Tails OS**, el poder de **Kali Linux** y la autonomía de un agente de IA nativo (**YrYs**).

### ✨ Características Clave

- 🚀 **Modo Fantasma:** Arranca desde USB, opera en RAM y borra todo al apagar. **Cero huellas digitales.**
- 🔒 **Persistencia Cifrada:** Guarda tus *skills*, configuraciones y modelos en una partición **LUKS** segura.
- 🤖 **Agente Autónomo (YrYs):** Ejecuta Nmap, Metasploit, Shodan y **crea scripts dinámicos** por ti sin intervención humana.
- 💻 **Multi-Arquitectura:** Optimizado nativamente para **Apple Silicon (M2/M3)** y entornos **Linux** x86_64/ARM.
- 🛠️ **Automatización Total:** Todas las herramientas de Kali Linux disponibles y automatizadas a tu alcance.

### 🚀 ¿Por qué KaliGhost?
A diferencia de Kali tradicional, KaliGhost **piensa y se adapta**. Ya no solo ejecutas herramientas; delegas la auditoría a un agente inteligente que aprende, crea *skills* personalizadas y opera con el anonimato de Tails.
