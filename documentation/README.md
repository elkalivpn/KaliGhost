## Project Overview

KaliGhost is a portable penetration testing operating system designed for cybersecurity professionals and ethical hackers. It features:

- **Autonomous AI Agent (YrYs)**: An intelligent assistant capable of planning and executing security assessments
- **Professional Cyberpunk GUI**: Advanced 3D interface with real-time system monitoring
- **Portable Design**: Runs natively on macOS M1/M2 chips without virtualization
- **Ghost Mode**: Secure deletion of all traces upon shutdown
- **Cloud Integration**: Optional AWS Bedrock integration for enhanced AI capabilities
- **Monetization Ready**: Integrated Gumroad support for commercial distribution
