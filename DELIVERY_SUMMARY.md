### Option 2: CLI (Most Powerful)
```bash

kalighost orchestrate execute "Build Go microservice" --mode ultra

# Security audit
kalighost security audit ./src --language go

# Monetization setup
kaligosh monetize tier "Professional" 29 --features "10K API calls"

# OSINT recon
kalighost threats recon competitor.com

# Infrastructure provisioning
kalighost infra provision myapp --provider aws --count 3

# Compliance check
kalighost compliance audit-compliance "MyCompany" --standards gdpr ccpa
```

### Option 3: Python API (Most Flexible)
```python
from backend.orchestrator import get_orchestrator, AgentMode
import asyncio

async def main():
    orchestrator = get_orchestrator()
    plan = await orchestrator.decompose_task(
        "Your task here",
        thread_id="my_task",
        mode=AgentMode.ULTRA  # Multi-agent
    )
    result = await orchestrator.execute_plan(plan)
    print(f"✅ Done: {result['status']}")

asyncio.run(main())
```
